# 机器人马拉松 · 数学速算与概念 PK · 产品需求文档

> 状态：草案 v0.1，待评审
> 日期：2026-11-13
> 适用系统：Elaine 学习系统（数学模块）
> 关联能力：现有英语「武道擂台」PK、星星积分、学习档案、AI 练功房、数学习题库与技能点账本

---

## 1. 背景与目标

数学模块已有 17 个技能点的自动出题器（口算、单位换算、大数、运算定律），但练习形式是单人答题，缺少像英语擂台那样「有对手、有画面、有输赢」的场景。孩子做速算时容易停在原地反复刷题，缺少把「算得快、算得准」直接变成可见优势的体验。

本产品在数学页签新增一款双人竞速游戏：两名玩家各选一台机器人，在标准 400 米跑道上跑 3 圈；答题正确提速、连击越高提速越猛、答错减速、连续答错摔倒重启。排位赛沿用英语擂台的星星规则（各交 50⭐，胜者得 75⭐），另提供无消耗的 AI 练习。

可观察的目标结果：

- 孩子能在首页两次点击内进入一局比赛，单局约 3–5 分钟结束；
- 答题表现直接、即时地反映在机器人速度、名次和画面上，孩子能说清「我为什么赢了/输了」；
- 每局结束后能看到本局错题、正确答案与解析，并能对可疑题目发起反馈；
- 排位赛的星星扣除、奖励、平局退款与掉线判负均有明确结果，不出现两边账目不一致。

## 2. 范围

### 2.1 P0（首版必须完整跑通）

| 能力 | 说明 |
|---|---|
| 双人排位 | 两台设备各登录一个学习档案，各扣 50⭐ 进入同一房间，胜者 +75⭐ |
| AI 练习 | 四档 AI，无报名费、无星星奖励，随时可退出 |
| 机器人选择 | 6 款机器人全部开放，各带一项轻微特性，可 3D 预览 |
| 赛道与镜头 | 标准 400 米跑道、3 圈、追尾视角、小地图、圈数与速度 HUD |
| 答题引擎 | 速算 3 : 概念 1 混合出题，双方题位与技能点一致 |
| 竞速规则 | 答对提速、连击倍率、答错减速、3 连错摔倒重启、冲线与时间上限 |
| 结算 | 胜负、星星变化、正确率、最高连击、摔跤次数、错题回顾 |
| 题目反馈 | 结算页复用「题目有问题」流程，可填写理由并由 AI 判断是否建单 |

### 2.2 P1（首版不做，预留）

- 观战、对局回放、自由视角；
- 机器人涂装自定义、按胜场解锁额外配色；
- 跨互联网匹配、好友邀请、排行榜与赛季；
- 主题赛道（夜间城市、太空站等）。

### 2.3 明确不做

- 机器人改装、养成、道具与付费；
- 同设备双人（上下分屏）：排位只支持两台设备跨设备对战；
- 比赛内语音、文字聊天、表情互动；
- 真实物理碰撞与互相阻挡（两台机器人各跑各的道，互不影响）；
- 用对战替代日常学习任务（对战不计入每日学习时长）。

## 3. 角色与对象

| 对象 | 说明 |
|---|---|
| 玩家档案 | 现有学习档案，含昵称、星星余额、数学技能点正确率、错题本 |
| 房间 | 一次对局的容器：房主、客队、模式（排位/AI 练习）、状态、房间码 |
| 对局 | 双方的速度、连击、连续答错数、圈数、已完成距离、题目序列、结果 |
| 机器人 | 款式、外观、一项轻微特性、动画状态（匀速、加速、摔倒、原地重启、冲线） |
| 题目 | 类型（速算/概念）、技能点、题干、正确答案、解析、选项（概念题） |

角色规则：

- 排位赛必须两个不同的学习档案，分别位于两台设备；同一档案不能同时占两个座位。
- 星星、技能点、错题本均属于档案，不随房间消失。
- 房间与对局是一次性的，结算或作废后不可恢复。

## 4. 核心流程

```text
首页 · 数学页签
  └─ 机器人马拉松
       ├─ 排位对战（各扣 50⭐）
       │    → 选机器人 → 建房 / 输入房间码加入 → 等待对手
       │    → 双方就绪 → 3 秒倒计时 → 比赛 → 结算 → 大厅
       └─ AI 练习（免费）
            → 选机器人 → 选 AI 档位 → 3 秒倒计时 → 比赛 → 练习结算
```

比赛内循环：

```text
出题 → 作答 → 判定
  ├─ 答对：连击 +1 → 按连击档位提速 → 0.35 秒后下一题
  ├─ 答错：连击清零 → 减速 → 连续答错 +1 → 1.2 秒展示答案后下一题
  └─ 连续答错达到 3 次：摔倒 → 原地待机 2 秒（题目暂停）→ 恢复基础速度
循环直到任一玩家完成 3 圈，或到达 8 分钟上限。
```

## 5. 功能需求

### FR-01 入口与模式选择

**目的**：让玩家从数学页签直接进入游戏，并明确区分「花星星的排位」与「免费的练习」。

**触发**：玩家在首页进入数学页签，点击「机器人马拉松」卡片。

**规则**：

- 未选择学习档案时，先进入档案选择；选择后回到模式页。
- 模式页展示当前星星余额，并提供两个入口：
  - **排位对战**：显示「报名费 50⭐ · 获胜 +75⭐」；
  - **AI 练习**：显示「免费 · 不计积分」。
- 星星余额不足 50 时，排位按钮置灰，提示「还差 X⭐，先去学习赚星星」，练习入口保持可用。
- 排位入口在点击后进入 FR-03；练习入口进入 FR-04。

**结果**：玩家进入对应模式；此时不扣星星。

**异常**：档案数据读取失败时停留在模式页并提示重试，不进入扣费流程。

---

### FR-02 机器人选择

**目的**：提供可挑选的参赛形象，强化「这是我的机器人」的代入感。

**触发**：进入排位或练习后，先进入机器人选择页。

**布局**：

- 左侧：6 款机器人卡片（名称、剪影、一句话特征）；
- 右侧：3D 实时预览，选中机器人原地跑动，可拖动旋转；
- 底部：已选机器人名称、「确认」按钮。

**款式（首版 6 款，均无属性差异）**：

| 名称 | 造型方向 |
|---|---|
| 疾风 | 长腿竞速型，约 1.85 m，深灰碳纤维骨架 + 红色关节光带，大步幅低步频 |
| 白鹭 | 轻量小个子，约 1.25 m，白色圆润外壳 + 青色面罩，高步频小碎步 |
| 铁犀 | 重装力量型，约 1.75 m，宽肩厚腿、液压关节、黑黄警示涂装，跑姿沉稳 |
| 游隼 | 流线冲刺型，约 1.6 m，银蓝外壳、背部散热鳍，身体前倾 |
| 赤兔 | 骨架外露型，约 1.7 m，橙色线束与铜色舵机，透明侧板，机械感强 |
| 星尘 | 轮足混合型，约 1.5 m，小腿末端带驱动轮，直道滑行、弯道步行（仅表现，不改变速度计算） |

**轻微特性**（每款只有一项，数值为差异化首版，试玩后微调）：

| 名称 | 轻微特性 |
|---|---|
| 疾风 | 极速上限 +0.2 m/s（9.2 m/s） |
| 白鹭 | 单次答对提速 +5%（0.21 m/s 起） |
| 铁犀 | 摔倒重启缩短 0.5 秒（1.5 秒） |
| 游隼 | 答错减速减少 0.2 m/s（−1.3 m/s） |
| 赤兔 | 连击倍率每档 +0.05（×1.05 至 ×1.85） |
| 星尘 | 起跑后前 10 秒速度 +0.3 m/s |

**规则**：

- 6 款全部默认可用，不需要解锁；特性只影响自己的速度与重启，不影响对手。
- 特性只有上表一项，不叠加；同款机器人特性相同；双方可以选同一款，通过颜色标识（我/对手）区分。
- 选机页需展示该机器人的特性一句话说明，不能只写外观描述。
- 特性带来的等效速度收益控制在约 ±3% 以内，不允许出现一款全面压制另一款。
- 造型参考公开报道中的马拉松人形机器人轮廓做原创演绎，**不直接使用任何品牌名称、商标或 1:1 复刻**。

**结果**：选择结果保存在本次对局中；结算页与「再来一局」沿用该选择。

### FR-03 房间与匹配（排位）

**目的**：让两台设备进入同一局，并保证报名费只在真正开局时被消耗。

**触发**：在模式页选择「排位对战」并确认机器人后。

**布局**：两个主按钮「创建房间」「加入房间」；创建后展示 6 位房间码与等待状态；加入时输入房间码。

**跨设备方式**：沿用英语擂台的做法，两台设备各登录一个不同档案、连接同一服务端，通过房间码进入同一局；不做同设备双人。

**规则**：

| 场景 | 处理 |
|---|---|
| 创建房间 | 立即扣除房主 50⭐，生成房间码，进入等待 |
| 等待期间取消 | 房主原数退回 50⭐，房间作废 |
| 加入房间 | 校验房间码存在、未满、未开局后，扣除加入者 50⭐ |
| 加入失败 | 房间不存在 / 已满 / 已开局 / 版本不一致：不扣星，提示具体原因 |
| 双方就绪 | 房主点击「开始」，或加入者进入后 3 秒自动开始（由房主设置，默认自动） |
| 双方都离开 | 房间作废，各自退还 50⭐ |

**结果**：进入 FR-05 倒计时；房间状态变为「进行中」。

**异常**：

- 房主在对手加入前掉线，房间保留 60 秒；超时作废并退星。
- 加入者扣星成功但进入失败时，立即原数退回，不允许出现「扣了星没进局」。

---

### FR-04 AI 练习

**目的**：让玩家在无成本、无压力的情况下熟悉操作和赛道。

**触发**：模式页选择「AI 练习」，确认机器人后。

**规则**：

- 不扣星星，胜利不发星星，失败无惩罚；结算明确标注「练习赛 · 不计积分」。
- 提供四档 AI，赛前选择：

| 档位 | AI 答题间隔 | AI 正确率 | 定位 |
|---|---|---|---|
| 简单 | 5.5 秒 | 50% | 刚接触游戏 |
| 普通 | 4.2 秒 | 65% | 正常练习 |
| 困难 | 3.4 秒 | 82% | 有挑战 |
| 冠军 | 2.6 秒 | 93% | 接近满速 |

- AI 与玩家使用同一套速度、连击、摔倒规则；AI 也会因连续答错摔倒重启。
- AI 随机使用一款机器人，其轻微特性同样生效，双方特性互不影响。
- 练习中允许暂停（暂停时双方速度冻结、题目隐藏）；排位不允许暂停。
- 玩家可随时退出练习，退出不判负、不扣星。
- 练习结果仍记录正确率、错题与技能点，但不计入星星与每日任务。

**结果**：进入倒计时并开始比赛。

---

### FR-05 赛前倒计时

**触发**：排位双方就绪，或练习模式选定 AI 档位后。

**规则**：

- 画面切到赛道起跑线，两台机器人并排（相邻两条跑道），镜头位于我方机器人后上方。
- 3、2、1 倒数，随后起跑提示音；倒计时期间题目面板遮罩，不可作答。
- 双方以基础速度 4.0 m/s 同时起跑，第一题在起跑后 0.6 秒出现。

**结果**：对局进入「比赛中」。

### FR-06 答题面板与出题

**目的**：把「算得快、概念清楚」变成赛道上的速度优势，同时保留草稿纸习惯。

**布局**（屏幕下半部分，约占 42% 高度）：

- 顶部：题号、题型（速算/概念）、当前连击、本局正确率；
- 中部：题干；速算为横式填空题，概念为四选一；
- 右侧/上方：「草稿纸」开关；
- 底部：速算为数字键盘 + 提交；概念为四个选项按钮；右下角「跳过」。

**出题规则**：

- 每 4 题为一个循环：**3 道速算 + 1 道概念**，循环重复。
- 双方在同一题位拿到**相同题型、相同技能点**的题目，但具体数值/选项不同，避免照抄答案。
- 速算取自现有 17 个技能点，首版权重：口算 40%、单位换算 20%、大数 20%、运算定律 20%；同一玩家连续两题不重复同一技能点。
- 概念题为四选一客观题，首版覆盖 8 类主要知识点，题库以「单局不重复、连续 3 局低重复」为准（首版约 80 道起），后续按学习进度持续补充：
  1. 计数单位与数位
  2. 大数读写与近似数
  3. 单位选择与换算
  4. 运算定律识别
  5. 线段、射线、直线与角
  6. 垂直与平行
  7. 平均数与统计图
  8. 可能性
- 概念题格式约束：题干不超过 40 字，选项不超过 12 字，解析不超过 40 字；一题只有一个正确答案。
- 同一玩家在同一局内不重复出现同一道概念题；相邻两局优先避开上一局出现过的题。
- 出题范围以沪教版四年级已学内容为准；具体单元与知识点映射需家长确认（见待确认问题）。

**作答规则**：

- 速算：数字键盘输入最终结果，提交即判定；支持小数（单位换算）与整千分位展示，不允许负数。
- 概念：点选选项即判定，不设二次确认。
- 草稿纸：可展开的半透明画板，覆盖题目区，支持手指/鼠标书写与一键清空；**展开时比赛不暂停**，收起后保留本题笔迹。
- 无单题限时；玩家可点「跳过」，跳过按答错处理。
- 判定在本地即时完成并立即反馈；对错结果同步给房间，双方看到的圈数与速度以统一结果为准。

**反馈规则**：

| 结果 | 反馈 | 下一题 |
|---|---|---|
| 答对 | 绿色高亮、机身加速特效、飘出「+0.20 m/s」 | 0.35 秒后 |
| 答错 | 红色抖动、正确答案高亮、展示一句解析 | 1.2 秒后 |
| 跳过 | 按答错处理，展示答案与解析 | 1.2 秒后 |
| 摔倒 | 题目区遮罩并显示「机器人重启中 2.0s」 | 原地重启结束后 |

**结果**：每题作答写入本局统计与错题记录。

### FR-07 速度、连击与加减速

**目的**：让「答得多、答得准、连击高」直接转化为可见的速度差，且规则能被孩子复述。

**基础模型**：

- 速度 v 的范围为 **2.5–9.0 m/s**（疾风上限 9.2），基础速度 **4.0 m/s**。
- 不答题时保持当前速度匀速前进，不自然衰减。
- 答对：`v = min(速度上限, v + 0.20 × 连击倍率)`；先使连击 +1，再按新连击数取倍率；速度上限与提速系数按所选机器人的特性修正。
- 答错：`v = max(2.5, v − 减速值)`，基础减速值 1.5 m/s（游隼 1.3）；连击清零，连续答错计数 +1。
- 跳过等同答错。

**连击倍率**：

| 当前连击 | 倍率 | 单次提速 |
|---|---|---|
| 1–2 | ×1.0 | +0.20 m/s |
| 3–5 | ×1.2 | +0.24 m/s |
| 6–9 | ×1.4 | +0.28 m/s |
| 10–14 | ×1.6 | +0.32 m/s |
| ≥15 | ×1.8 | +0.36 m/s |

**连击节点反馈**（不改变数值，只做画面与音效强调）：

| 连击 | 表现 |
|---|---|
| 3 | 机身灯带亮起，脚步出现气流线 |
| 6 | 速度线增强，HUD 连击条变色 |
| 10 | 机身进入「超频」外观（金色光带 + 残影） |
| 15 | 全场播报「超频」，镜头轻微拉远 |

**结果**：速度变化立即反映在机器人位移、HUD 速度条与名次差距上。

**异常**：同一题重复提交只计一次；提交后到下一题出现前的重复点击忽略。

---

### FR-08 摔跤与重启

**目的**：让连续失误有明确、可理解的代价，同时不直接结束比赛。

**触发**：同一玩家**连续答错（含跳过）达到 3 次**。

**规则**：

- 机器人失去平衡、火花与碎片特效、镜头短暂震动，随后倒地；**停在摔倒位置原地待机**，不回到起点、不重开比赛、不重置圈数与已完成距离；速度归零。
- 题目区被遮罩，显示「系统重启中」与 2、1 倒数，**重启期间不能答题**。
- 2.0 秒后机器人原地起身继续跑，速度恢复为基础 4.0 m/s（铁犀 1.5 秒）；连击、连续答错计数清零。
- 摔倒期间对手正常答题与前进，不受影响。
- 一局内摔倒次数不限，计入结算统计。
- 本题不计为答错之外的其他惩罚；此前的错题仍进入错题回顾。

**结果**：对局继续，位置差距通常在此刻被拉开。

**异常**：若摔倒期间对局因对手冲线或时间到结束，直接进入结算，不再执行重启。

---

### FR-09 圈数、冲线与时间上限

**规则**：

- 赛道为标准 400 米一圈，共 **3 圈，总程 1200 米**；两条跑道均按 400 米/圈计算，不因道次产生距离差。
- 每完成一圈，HUD 圈数 +1，并播放单圈提示；进入第 3 圈时播报「最后一圈」。
- **首位完成 1200 米的玩家立即获胜**，比赛结束，双方进入结算；未完成方记录已跑距离。
- 单局时间上限 **8 分钟**。到点时无人冲线，按以下顺序判定：
  1. 已完成距离更远者胜；
  2. 距离相同，比较本局正确率（答对 ÷ 已答）；
  3. 仍相同，比较最高连击；
  4. 仍相同，判平局（各退 50⭐）。
- 比赛中不设暂停；排位赛中途退出按 FR-14 判负。

**结果**：产生唯一结果（胜/负/平）与双方成绩数据。

---

### FR-10 赛道、镜头与小地图

**目的**：用接近真实的 3D 画面呈现「机器人马拉松」，同时保证信息一眼可读。

**赛道场景**：

- 标准 8 道 400 米塑胶跑道：红色跑道、白色分道线、绿色内场、起终点门架、看台、灯柱。
- 环境光为傍晚/夜间体育场照明，跑道有轻微反光；远处城市轮廓与广告牌作背景。
- 两台机器人分别位于相邻跑道（例如第 3、5 道），互不碰撞、互不遮挡。

**镜头**：

- 追尾视角：相机位于我方机器人后上方，能看到机器人**完整全身**与前方约 20 米赛道。
- 速度提升时相机略微后拉、视野变宽；超频时出现轻微速度线与动态模糊。
- 摔倒时切换近景 1.2 秒再回到追尾位；冲线时切侧前方定格 1.5 秒。
- 首版不提供自由视角与回放（P1）。

**小地图**（右上角）：

- 椭圆跑道缩略图，两个色点表示我与对手，标注各自圈数；
- 显示领先/落后差距（米），差距小于 5 米时显示「贴身」；
- 不显示题目答案或对手答题对错。

**画面标识**：

- 我方机器人头顶显示昵称与「我」标识；对手显示昵称与「对手」标识。
- 两款机器人同款时，用脚下光环颜色区分（我方青色、对手橙色）。

### FR-11 比赛 HUD

| 区域 | 内容 |
|---|---|
| 顶部左 | 当前圈数（1/3）、已完成距离 / 1200 米、本局计时 |
| 顶部中 | 名次（第 1 / 第 2）与差距 |
| 顶部右 | 小地图 |
| 画面左下 | 我方速度条（2.5–9.2 m/s）、当前速度数字 |
| 画面右下 | 对手速度条与连击（仅显示连击数，不显示对错） |
| 题目区上方 | 连击数、连击倍率、本局正确率 |
| 中央 | 连击节点、摔倒重启、最后一圈、冲线等全屏提示 |

规则：

- HUD 数字每 0.2 秒刷新一次即可，避免跳动过快。
- 对手速度条只展示速度与连击，不展示其题目内容。
- 所有提示不遮挡题目主体；摔倒遮罩除外。

### FR-12 结算

**触发**：任一玩家冲线、时间到、对手掉线或主动退出。

**布局**：上半屏保留赛道定格画面与两台机器人；下半屏为结算面板。

**结算内容**：

| 模块 | 内容 |
|---|---|
| 结果标题 | 冲线获胜 / 对手掉线 / 时间到 / 平局 / 练习完成 |
| 星星变化 | 胜 +75⭐；负 0；平局 +50⭐（退还报名费）；练习 0 |
| 本局数据 | 用时、完成圈数与距离、正确率、答对/答错数、最高连击、摔倒次数、平均速度 |
| 对手信息 | 档案昵称、机器人款式 |
| 错题回顾 | 逐题展示题干、我的答案、正确答案、一句解析 |
| 题目反馈 | 每题右侧「题目有问题」按钮 |
| 操作 | 再来一局（同模式）、换机器人、返回大厅 |

**规则**：

- 排位赛星星变化只结算一次；结算面板展示的是结算后的余额。
- 错题进入现有数学错题本；同一题多次答错只保留一条并累计次数。
- 练习赛结算标注「练习赛 · 不计积分」，不显示星星变化。
- 「再来一局」回到房间/练习准备页，不自动扣星；排位需重新建房或加入。
- 结算页不自动跳转，必须由玩家点击离开。

**题目反馈流程**（复用现有数学反馈能力）：

1. 点击「题目有问题」，选择理由：题干不清 / 答案有误 / 超出所学 / 其他；
2. 选择「其他」时必须填写不少于 5 个字的说明；
3. 提交后由 AI 判断是否构成需修改的题目问题；
4. 判定为问题题目时，进入现有修改任务清单，并在后续出题中不再出现；
5. 判定不成立时提示「已记录，会继续观察」，不改动题库。

**异常**：结算请求失败时保留本局数据，显示「重新获取结算」按钮；不重复加星。

### FR-13 积分规则（排位）

| 场景 | 星星变化 |
|---|---|
| 创建房间 / 加入房间 | −50⭐（报名费） |
| 获胜 | +75⭐（报名费不退，净 +25） |
| 失败 | 0（报名费不退） |
| 平局 | +50⭐（退还报名费） |
| 对手掉线 / 对手主动退出 | 我方 +75⭐，对方不退报名费 |
| 双方均掉线 / 均退出 | 各退 50⭐，房间作废 |
| 等待阶段取消 | 房主 / 加入者原数退回 50⭐ |
| AI 练习 | 0（不扣不发） |

补充规则：

- 排位与英语擂台共用同一星星池。
- 对局中的答题**不触发**数学单题星星奖励，避免用对战刷星；只有胜负结算产生星星变化。
- 星星不足以支付 50⭐ 时不能进入排位，练习不受限。
- 所有星星变化以对局最终结果为准，客户端展示的余额仅作显示。

### FR-14 异常、退出与掉线

| 场景 | 处理 |
|---|---|
| 排位中主动退出 | 二次确认「退出将判负并扣除 50⭐ 报名费」；确认后判负，对手获胜 |
| 排位中关闭页面 | 视为主动退出；对手在 8 秒后收到胜利结算 |
| 断线 ≤ 8 秒 | 恢复后继续比赛，当前题作废并换下一题，速度与位置按对局状态恢复 |
| 断线 > 8 秒 | 判负，对手获胜；报名费不退 |
| 对手掉线 | 我方立即进入胜利结算，显示「对手掉线」 |
| 双方同时掉线 | 房间作废，各退 50⭐ |
| 练习中退出 | 直接结束，不判负、不扣星 |
| 比赛服务异常 | 本局作废，双方各退 50⭐，提示重新开局 |

规则：

- 任何异常都不允许出现「一方扣星、另一方未结算」的悬空状态；无法判定时按双方退款处理。
- 比赛内不弹广告、不弹学习提醒、不自动跳转。

### FR-15 学习数据与题目反馈

**规则**：

- 每局记录：模式、对手、机器人款式、用时、圈数、距离、答对/答错、最高连击、摔倒次数、每题作答与技能点。
- 对局答题**计入**数学技能点正确率与错题本，用于后续出题难度与错题复习。
- 对局答题**不计入**每日学习时长、每日任务进度与连续学习天数（避免用对战替代日常学习）。
- AI 练习同样记录，但标记为「练习」，在统计中与排位分开。
- 「题目有问题」反馈只从结算页发起，比赛中不提供入口，避免打断比赛。
- 反馈判定与建单复用现有数学模块的 AI 分流流程；被判定为问题的题目后续不再生成。

## 6. 共享规则

### 6.1 首版数值表（可在试玩后调整）

| 答错减速 | −1.5 m/s，最低 2.5 m/s（游隼 −1.3） |
| 摔跤阈值 | 连续答错 3 题 |

### 6.2 判定优先级

1. 先判定冲线（首位完成 1200 米）；
2. 再判定时间上限（距离 → 正确率 → 最高连击 → 平局）；
3. 再判定掉线/退出（在线方获胜）；
4. 以上都不成立时对局继续。

同优先级内只产生一个结果，不允许同时出现「胜利」与「平局」两种结算。

### 6.3 公平性规则

- 双方题位、题型、技能点一致，仅具体题目不同。
- 机器人只提供 FR-02 表中的一项轻微特性，不叠加、不隐藏；同款特性相同，双方可自由选择。
- 特性带来的等效速度收益控制在约 ±3% 以内，避免一款全面压制另一款。
- 双方同时起跑、同一套速度规则、同一时间上限。
- 不设「落后加速」等隐藏补偿；差距只来自答题表现。
- 对手的题目内容、答案与对错不展示。

### 6.4 对局状态机

| 状态 | 进入条件 | 可执行操作 | 离开条件 |
|---|---|---|---|
| 大厅 | 进入游戏 | 选模式、看余额 | 选排位/练习 |
| 选机器人 | 选定模式 | 预览、确认 | 确认后建房/选 AI |
| 等待对手 | 建房成功 | 取消（退星）、展示房间码 | 对手加入 / 取消 / 超时 |
| 倒计时 | 双方就绪 | 无 | 3 秒结束 |
| 比赛中 | 倒计时结束 | 答题、跳过、草稿纸、退出 | 冲线 / 时间到 / 掉线 |
| 摔跤重启 | 连续答错 3 题 | 无（题目暂停） | 原地待机 2 秒结束 |
| 结算 | 产生结果 | 查看错题、反馈、再来一局 | 返回大厅 |
| 已作废 | 双方退出/服务异常 | 无 | 退款完成 |

### 7.2 视觉与音效

- 3D 实时渲染（three.js），机器人使用骨骼动画的跑步循环；加速时步频与摆臂幅度提升。
- 加速：脚底尘土/气流、机身灯带增亮；超频：金色光带、残影、速度线。
- 摔倒：踉跄、火花、零件轻弹、镜头震动；原地重启：机器人停在摔倒位置待机，胸口指示灯由红转绿后继续跑。
- 冲线：彩带/计时牌定格，显示「第 1 名 / 用时」。
- 音效：起跑枪、脚步、加速、答对、答错、摔倒、重启完成、冲线、最后一圈提示。
- 默认开启音效，提供静音开关并记住选择。
- 不出现血腥、危险动作模仿提示；摔倒动画保持在机械结构层面。

### 7.3 设备与性能

- 首版面向 iPad Safari 与桌面浏览器，横屏优先；触控目标不小于 44×44 px。
- 目标 60 fps；检测到持续掉帧时自动降级（关闭阴影、减少粒子与观众数量），不低于 30 fps。
- 局域网内首次进入游戏的加载时间目标不超过 5 秒；比赛过程不因资源加载卡顿。
- 页面切到后台超过 8 秒按掉线处理。

## 8. 典型场景

**场景 A · 排位正常开局**
孩子 A 在 iPad 上进入数学页签 → 机器人马拉松 → 排位 → 选「疾风」→ 创建房间，扣 50⭐ → 孩子 B 在另一台设备输入房间码加入，扣 50⭐ → 倒计时 → 双方起跑。A 连续答对 7 题，速度升到 5.7 m/s，小地图显示领先 32 米；B 第 2 圈连续答错 3 题摔倒，原地重启 2 秒。A 先完成 3 圈，结算 +75⭐，B 查看错题回顾。

**场景 B · 平局与退款**
双方都未能在 8 分钟内完成 3 圈，距离相同、正确率相同、最高连击相同 → 判平局，各退 50⭐，结算显示「平局 · 报名费已退回」。

**场景 C · 星星不足**
孩子星星余额 32⭐，排位按钮置灰，提示「还差 18⭐」；点击 AI 练习 → 选「普通」→ 免费对局，结束后结算标注「练习赛 · 不计积分」。

**场景 D · 对手掉线**
比赛中对手网络中断超过 8 秒 → 我方立即进入结算，显示「对手掉线」，+75⭐；对手重连后看到「你已掉线判负」，报名费不退。

**场景 E · 题目反馈**
结算错题回顾中，孩子点击某道概念题的「题目有问题」→ 选择「答案有误」并补充说明 → 提交 → AI 判定成立 → 该题进入修改任务清单，后续对局不再出现。

## 9. 待确认问题（仅剩数值校准）

产品规则已确认，以下只影响手感，不阻塞开发；首版按表中数值实现，试玩后调整：

1. **机器人特性强度**：6 款特性按「等效速度收益约 ±3%」设计，需实机对局校准；若某款明显更强，优先削弱该款，不加强其他款。
2. **比赛节奏**：基础速度 4.0 m/s、单次提速 0.20 m/s、3 圈 1200 米的组合，目标单局 3–5 分钟；需用孩子真实答题速度验证，必要时只调基础速度与提速值，不改赛道距离与圈数。
3. **概念题补充顺序**：首版 8 类按当前教学进度排优先级，后续由家长指定单元补充。
