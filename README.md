# Elaine 学习中心

面向家庭学习的语文、数学和英语练习应用，包含单词闯关、攻城 PK 和机器人马拉松。通过浏览器使用，由 Python 服务提供学习档案、对战同步和语音等功能。

## 功能

- **语文和数学**：字词、拼音、计算与单位换算等练习，记录答题和复习情况。
- **英语**：句子练习、单词学习和闯关游戏。
- **攻城 PK**：答题驱动的攻城对战，支持 AI 练习和双人对战。
- **机器人马拉松**：答题提速、四台机器人同场比赛，支持 AI 练习和好友对战。
- **学习档案**：按名字保存进度和星星；可选配置 AI 助手与语音。

## 快速开始

需要 Python 3 和支持 JavaScript、Canvas 与 WebGL 的现代浏览器。项目自带 Three.js，无需 Node.js 即可运行应用。

```bash
git clone https://github.com/jacwuha-lang/Elaine-study.git
cd Elaine-study
python3 server.py
```

Windows 中可使用 `python server.py` 或 `py server.py`。服务默认监听本机 `8777` 端口，并尝试自动打开浏览器；也可以手动访问 <http://127.0.0.1:8777/>。在首页选择或创建学习档案即可开始。

请通过上述服务访问，不要直接双击打开 HTML：档案、对战和部分功能需要服务端接口。结束时在运行服务的终端按 `Ctrl+C`。

### 可选：安装在线语音

```bash
python3 -m pip install -r requirements.txt
```

依赖中的 `edge-tts` 用于在线语音，安装和使用需要网络；未安装时应用仍可运行，语音可回退到浏览器支持的语音。Windows 请将命令中的 `python3` 换成 `python` 或 `py`。

## 手机、平板及双人对战

让运行服务的电脑和其他设备连接同一局域网，在电脑上启动：

```bash
python3 server.py --host 0.0.0.0 --port 8777
```

在手机或平板浏览器中打开终端显示的 `http://电脑局域网IP:8777/`。如无法连接，请检查 Wi-Fi、电脑防火墙及 8777 端口。Windows 也可使用项目里的 `start-lan.bat`；该脚本会尝试配置防火墙，请按系统提示操作。

双人对战时，两台设备使用不同的学习档案，进入同一游戏；一方创建房间，另一方输入房间号加入。单人可以选择 AI 练习。

局域网模式会让同一网络中的设备访问服务和档案接口，请只在可信网络中使用，勿直接暴露到公网。

## AI 与语音配置

- **DeepSeek 助手**：在应用设置中填写自己的 API Key，或在启动服务前设置 `DEEPSEEK_API_KEY` 环境变量。接口调用需要网络及有效的服务账户，可能产生费用；不配置仍可使用基本练习和游戏。
- **语音**：安装可选的 `edge-tts` 后可使用在线语音；也可按需运行 IndexTTS2，并用 `--tts` 指定其地址。可用 `python3 server.py --help` 查看其他参数。

请勿把 API Key、学习档案或缓存上传到公开仓库。环境变量优先于应用内保存的 Key。

## 数据与目录

| 路径 | 用途 |
| --- | --- |
| `server.py` | 本地服务、档案和对战接口 |
| `index.html`、`js/`、`css/` | 学习中心和游戏界面 |
| `math-pk.html`、`js/math-pk/` | 机器人马拉松 |
| `arcade/` | 单词闯关 |
| `data/` | 语文题库数据 |
| `assets/`、`vendor/` | 运行所需的素材和第三方库 |
| `profiles/` | 本机学习档案，需自行备份 |
| `.cache/` | 本机语音缓存和应用内保存的 AI 配置 |

档案和缓存默认不纳入 Git。更换电脑时，应自行备份并恢复需要的 `profiles/` 档案；浏览器本地数据也可能包含学习状态。

## 常见问题

- **端口被占用**：运行 `python3 server.py --port 8778`，并访问 `http://127.0.0.1:8778/`。
- **其他设备打不开**：确认启动命令带有 `--host 0.0.0.0`，设备在同一网络，并检查防火墙。
- **画面空白或 3D 游戏无法运行**：使用较新的浏览器，启用 JavaScript 和硬件加速，并确认 WebGL 可用。
- **AI 或在线语音不可用**：检查网络、相应依赖和 Key；基础学习和游戏可以继续使用。
